# Debt_Safe_Farming

An AI concept model designed to help Indian farmers plan farming decisions safely and avoid falling into debt.

## Problem
Many farmers fall into debt due to wrong crop selection, high input costs, and unplanned farming decisions.

## Solution
This system provides:
- Low-risk crop suggestions
- Expense warnings
- Financial risk level (Low / Medium / High)
